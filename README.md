# Federico Bergamini

PhD student at the [University of Luxembourg](https://www.uni.lu/snt-en/), in the [Software Verification and Validation group](https://www.uni.lu/snt-en/research-groups/svv) of SnT, working on metamorphic security testing assisted by large language models.

Before the PhD I was a research fellow at the University of Milano-Bicocca, where I built FHIR-based backends for remote patient monitoring in the ANTHEM digital-health project. Earlier I worked as an embedded software engineer in aerospace and defence and taught computer science at a technical high school. I hold a BSc and an MSc in Computer Science from Milano-Bicocca.

I mostly build backend services on the JVM, networked and low-level software in Rust, and simulations and tooling in Python.

## Selected work

- [sip](https://github.com/Fede-Berga/sip): Service that correlates security events (auth, network, system, industrial-control) into severity-rated findings. Java 25, Spring Boot 4, hexagonal multi-module Gradle build, Postgres, Redis, Liquibase.
- [ktor-crud-rbac-demo](https://github.com/Fede-Berga/ktor-crud-rbac-demo): REST API in Kotlin and Ktor with JWT authentication, role-based access control, Exposed on Postgres, Redis caching, token blacklist and rate limiting, Prometheus and Grafana metrics.
- [udp-tokio-stack](https://github.com/Fede-Berga/udp-tokio-stack): Asynchronous UDP unicast, broadcast and multicast in Rust with Tokio and a typed bincode wire format.
- [eco](https://github.com/Fede-Berga/eco): Echolocation browser game in vanilla JavaScript: cellular-automata caves, raycast sound pings, a predator that hunts by ear, synthesized Web Audio. [Play it in the browser](https://fede-berga.github.io/eco/).
- [satellite_routing](https://github.com/Fede-Berga/satellite_routing): Code of my MSc thesis, a SimPy simulation of SDN source routing for load balancing in an Iridium-like LEO constellation.
- [mise](https://github.com/Fede-Berga/mise): Multi-tenant restaurant operations platform: FastAPI microservices, Next.js, Keycloak, NATS JetStream.

Teaching material I wrote for my high-school classes: [networking-lab](https://github.com/Fede-Berga/networking-lab) and [php-guestbook](https://github.com/Fede-Berga/php-guestbook).
