# Federico Bergamini

PhD student at the [University of Luxembourg](https://www.uni.lu/snt-en/), working on automated penetration testing with large language models, in collaboration with the Luxembourg National Cybersecurity Competence Center (NC3).

Before the PhD I was a research fellow at the University of Milano-Bicocca, where I built FHIR-based backends for remote patient monitoring in the ANTHEM digital-health project. Earlier I worked as an embedded software engineer and taught computer science in a high school. I hold a BSc and an MSc in Computer Science from Milano-Bicocca.

Website, publications and CV: [fede-berga.github.io](https://fede-berga.github.io)

## Selected work

- [sip](https://github.com/Fede-Berga/sip): turns security events into severity-rated findings. Java 25, Spring Boot 4, hexagonal multi-module Gradle build.
- [ktor-crud-rbac-demo](https://github.com/Fede-Berga/ktor-crud-rbac-demo): Kotlin and Ktor REST API with JWT, role-based access control, Redis caching and Prometheus metrics.
- [udp-tokio-stack](https://github.com/Fede-Berga/udp-tokio-stack): asynchronous UDP unicast, broadcast and multicast in Rust with Tokio.
- [eco](https://github.com/Fede-Berga/eco): echolocation game in vanilla JavaScript: find a pitch-black cave's exit by ear. [Play it](https://fede-berga.github.io/eco/).
- [satellite_routing](https://github.com/Fede-Berga/satellite_routing): my MSc thesis, a simulation of SDN source routing in an Iridium-like LEO constellation.
- [mise](https://github.com/Fede-Berga/mise): multi-tenant restaurant platform on FastAPI microservices, Next.js and Keycloak.

Teaching material from my high-school classes: [networking-lab](https://github.com/Fede-Berga/networking-lab) and [php-guestbook](https://github.com/Fede-Berga/php-guestbook).
